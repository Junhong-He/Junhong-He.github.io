### 关键教训
- ❌ **不要自己写/改 SCSS/CSS 框架文件**——原模板的 SCSS 在 GitHub Pages 上能正常编译，手改必出兼容性问题
- ✅ **正确做法：模板原版一个字不动，只改内容文件**
- GitHub Pages 的 SCSS 编译环境有白名单插件限制，Susy 等第三方库不可用
- 根目录不能有 `index.html`，否则跳过 Jekyll 构建

### Build #29 失败修复（commit 9776a81）
**根因**：`main.scss` 第 16 行 `@import "vendor/susy/susy"` 和第 37-40 行引用的 font-awesome/magnific-popup 全部缺失。`_sass/vendor/` 目录下只有 `breakpoint/_breakpoint.scss` 一个文件，缺少：
- breakpoint 的其他 17 个文件（特别是 `_settings.scss` → 报错 "File to import not found: settings"）
- font-awesome/ 整个目录（17 个文件）
- magnific-popup/ 整个目录（2 个文件）
- susy/ 整个目录（56 个文件）

**修复**：通过 Agent 用 codeload tarball 方式从原仓库下载完整的 `_sass/vendor/` 子树（93 个文件），逐字节与原版一致。

### 图标修复（commit bb85545）
